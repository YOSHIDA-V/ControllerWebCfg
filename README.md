# VS-ControllerWebCfg

VS-C4ファームウェア`v1.0`向けのWeb設定ツールです。ChromeまたはEdgeのWeb Bluetoothを使い、VS-C4の設定と本体メンテナンスを行います。

## 公開ページ

- [VS-C4 Web設定](https://yoshida-v.github.io/ControllerWebCfg/)
- [VS-C4 ヘルプ](https://yoshida-v.github.io/ControllerWebCfg/help.html)

通常のコントローラー設定は「詳細設定」を使用します。ファームウェア更新、再起動、初期化、内部ファイル管理は「本体メンテナンス」にまとめています。

## 注意

- 設定のために接続する前に、VS-C4から接続中のコントローラーを切断してください。
- ファームウェア更新では、VS-C4用ファームウェアを選択してください。

## 参考

このツールはBlueRetro WebCfgをVS-C4ファームウェア`v1.0`向けに調整したものです。元BlueRetro側の資料は参考情報として扱います。
