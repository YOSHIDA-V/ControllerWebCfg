# VS-ControllerWebCfg

VS-C4向けのWeb設定ツールです。ChromeまたはEdgeのWeb Bluetoothを使い、VS-C4の詳細設定、プリセット設定、システム管理、ファームウェア更新、ファイル管理を行います。

## 公開ページ

- [VS-C4 Web設定](https://yoshida-v.github.io/ControllerWebCfg/)
- [VS-C4 ヘルプ](https://yoshida-v.github.io/ControllerWebCfg/help.html)

## 注意

- 設定のために接続する前に、VS-C4から接続中のコントローラーを切断してください。
- ファームウェア更新では、VS-C4用ファームウェアを選択してください。

## 参考

このツールはBlueRetro WebCfgをVS-C4向けに調整したものです。元BlueRetro側の資料は参考情報として扱います。
